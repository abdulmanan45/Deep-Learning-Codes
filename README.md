# Implementations from *Deep Learning with Python* (François Chollet)  

This repository contains my implementations of deep learning concepts and codes from the book *Deep Learning with Python* by François Chollet. The implementations cover various topics, including binary classification, multiclass classification, and scalar regression using neural networks; ccomputer vision and more.  

## Running the Notebooks  

You can run the notebooks in Jupyter, Google Colab, or Kaggle, depending on resource needs.
