# ConvNet Implementations from *Deep Learning with Python* (François Chollet)  

This repository contains implementations of Convolutional Neural Networks (ConvNets) from the book *Deep Learning with Python* by François Chollet. The models were run in different environments based on resource requirements.  

## Notebooks  

- **`convnet.ipynb`** – Run locally on my machine.  
- **`convnetcholletbook.ipynb`** – Executed on Kaggle due to higher resource demands.  

Both notebooks follow the book's implementations and explore ConvNets for image classification tasks specificaly classifying cats and dogs from the Kaggle Cats and Dogs Dataset https://www.microsoft.com/en-us/download/details.aspx?id=54765. There are corrupted images in the dataset which were removed in the code implementation run locally. The kaggle implementation utilised the dataset at https://www.kaggle.com/datasets/joejoe79/asirra through kaggle notebook input. This dataset already has the corrupted iamges removed.   

You can run the notebooks in Jupyter or Google Colab for further exploration.
